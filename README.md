# AI Совёнок (ES-AI-Mod)

AI-мод для **«Бесконечного лета»** (Steam, appid 331470, движок Ren'Py 7.4.11):
персонажи игры разговаривают с тобой через LLM, озвучивают реплики (TTS) и понимают
голос (STT). Только связь игры с Python-сервером идёт по localhost. Облачные
LLM/TTS/STT отправляют провайдерам текст, контекст диалога или аудио; edge-tts тоже
использует внешний сервис. Для локальной обработки нужны локальные провайдеры.
Исходные архивы игры не изменяются, мод живёт
в `game/mods/es_ai/` (ручная установка) или в папке мастерской Steam
`steamapps/workshop/content/331470/3809240310/` — мод сам определяет, где лежит.

## Как это работает

```
Бесконечное лето (Ren'Py 7.4.11, Python 2.7)
   │  game/mods/es_ai/*.rpy — тонкий клиент: чат, спрайты, экраны, say-хук
   │  HTTP 127.0.0.1:40310
   ▼
ES AI Server (Python 3, ядро на стандартной библиотеке)
   ├─ LLM   — любой OpenAI-совместимый /chat/completions
   │          (Groq, Mistral, OpenRouter, OpenAI, NVIDIA, Cohere, Cerebras,
   │           GitHub Models, Ollama, LM Studio, свой URL)
   ├─ TTS   — Fish Audio, ElevenLabs, edge-tts, OpenAI, Windows SAPI, свой;
   │          мужской и женский голос у каждого провайдера
   ├─ STT   — Groq/OpenAI Whisper, локальный faster-whisper, диктовка Windows (Win+H)
   └─ память — личная история, сжатие и публичные реплики, услышанные участниками
```

Порт сервера — **40310** (хвост id мода в мастерской 3809240310), чтобы не конфликтовать с другими AI-модами
(например, llama-сервер AI_lena на 8080). Настройки и их путь зависят от варианта
установки; см. раздел «Данные и приватность».

## Возможности

* **Чат с персонажами** — 11 персонажей: Славя, Алиса, Лена, Ульяна, Мику, Женя,
  Шурик, Ольга Дмитриевна, Юля, Электроник, Виола. Реплика AI сопровождается сменой
  спрайта: LLM возвращает `(эмоция) текст`, эмоция маппится в валидный тег спрайта
  игры (словари эмоций сверены с `sprites.rpyc`).
* **Озвучка (TTS)** — ответы персонажей озвучиваются, у каждого персонажа свой голос.
  Провайдеры: Fish Audio, ElevenLabs, edge-tts (бесплатно), OpenAI, Windows SAPI,
  свой OpenAI-совместимый. Есть общие мужской/женский голоса, индивидуальные
  настройки провайдера и голоса персонажа и отдельное прослушивание его голоса.
* **Озвучка романа** — опционально озвучиваются и оригинальные реплики новеллы
  (say-хук перехватывает реплики, имя персонажа → id → голос).
* **Голосовой ввод (STT)** — пункт «Сказать голосом»: запись с микрофона до 8 секунд
  с авто-остановкой по тишине, распознавание через Whisper, текст вставляется в поле
  ввода. Есть режим диктовки Windows (Win+H).
* **Память** — личная история каждого персонажа и LLM-сжатие старых сообщений;
  вкладка «История». Публичная память хранит только реально доставленные реплики
  для участников-свидетелей, а не частные разговоры или выдуманные факты.
* **Групповые сцены и камео** — до 7 персонажей: основной собеседник и до 6
  дополнительных, с учётом лимита настроек и вместимости локации. Можно обращаться
  к присутствующим по имени, приглашать других, идти с выбранными спутниками;
  находящиеся рядом NPC не считаются автоматически участниками разговора.
* **Занятия NPC** — отключаемый тумблер, по умолчанию включён. Простые заданные
  правила по фазе дня определяют занятия и места, но фактическое присутствие
  важнее расписания. Вызов из другой локации может задержаться на 1-3 успешных
  обмена репликами; Виола не оставляет медицинское дежурство. Это не полностью
  динамическая симуляция расписаний и не таймерный опрос LLM.
* **Смена собеседника** — автоматический выбор основного персонажа по обращению
  включается отдельно (`scene_auto_primary`), по умолчанию выключен.
* **Карта и перемещения** — 49 связанных локаций, включая интерьеры, бункер,
  участки шахты и автобус 410. Иллюстрированная карта с фандом-вики поддерживает
  зум, перетаскивание и маркер «вы здесь»; доступный фон выбирается для места и фазы.
* **Действия сцены** — уже реализованы теги `[action:goto:...]`, `[action:time:...]`,
  `[action:dress:...]` и камео. Одежда учитывает текущую сцену, просьбы игрока,
  вечеринки и ночной пляж; праздничные наряды доступны только там, где есть
  соответствующие спрайты (Лена, Славя, Ульяна, Ольга Дмитриевна).
* **Сюжетные события** — выключены по умолчанию; интенсивность `low`, `medium`
  или `high`. Ограниченная система поводов и продолжений с учётом участников и
  контекста, а не генератор полностью произвольного сюжета.
* **Игровые часы** — выключены по умолчанию. Настраиваются начальное время и
  0-120 минут за обмен репликами; часы задают фазу суток. Отдельный переключатель
  «Показывать время» скрывает показания, не отключая часы (при включённых часах
  показ по умолчанию включён).
* **Инициатива** — «Пусть заговорит сам»: персонаж начинает разговор первым.
* **Окно настроек** — нативное окно поверх игры (tkinter): LLM, голос, микрофон,
  промпты, история, карта и параметры сцены. Есть экспорт/импорт данных. Язык
  интерфейса **Русский / English** (голоса edge-tts подставляются под язык).
* **Горячая клавиша `A`** — AI-чат с текущим персонажем прямо в сцене новеллы.

## Установка

1. **Выбери вариант установки.** Для Workshop подпишись на мод
   [AI Совёнок](https://steamcommunity.com/sharedfiles/filedetails/?id=3809240310)
   и дождись загрузки Steam. Для исходников GitHub запусти
   `ES-AI-Mod/installer.pyw`: он устанавливает проектный вариант в
   `game/mods/es_ai/`, а не обновляет Workshop.
   CLI из корня репозитория:
   `python ES-AI-Mod/installer.pyw --install "D:\...\Everlasting Summer"`.
   Перед ручным обновлением сделай отдельную резервную копию пользовательских
   данных; не полагайся на установщик как на полный бэкап истории и персон.
2. **Провайдер и ключ** — прямо в игре: при первом входе в мод открывается окно
   настроек «AI Совёнок». Провайдеры в порядке `LLM_MAP`/списка интерфейса:
   Groq / Mistral / OpenRouter / OpenAI / NVIDIA / Cohere / Cerebras / GitHub /
   Ollama / LM Studio / Свой. Вставь ключ и нажми «Проверить LLM». То же окно доступно
   из чата («Настройки AI») или двойным кликом по `server/settings.pyw`.
3. **TTS/STT-компоненты** — кнопка «Установить/обновить компоненты» в том же окне
   (ставит `edge-tts`, `sounddevice`, `numpy` через pip).

Сервер стартует автоматически вместе с игрой (нужен Python 3). Ручной запуск без
консоли: `server/start_server.pyw` внутри выбранной установки.

## Данные и приватность

* **Проект/ручная установка:** `config_loader.py` читает и сохраняет локальные
  `server/config.json` и `server/keys.json`. История находится в
  `server/memory/conversations/`; прочие данные используют проектные пути.
* **Workshop:** загрузчик содержит `DEFAULT_CONFIG` для нового пользователя;
  настройки, ключи, персоны, память и журналы находятся в
  `%LOCALAPPDATA%\AI.Sovenok` (при отсутствии переменной - в `AI.Sovenok` внутри
  домашней папки).
  Если создать папку данных нельзя, загрузчик возвращается к локальной `server/`.
  Старые локальные данные копируются при миграции только при отсутствии целевых;
  встроенные defaults не накладываются поверх существующего пользовательского конфига.
* Это **разные варианты runtime**, не взаимозаменяемые деревья файлов: отличаются
  загрузчики, пути данных, запуск настроек и отдельные контракты ключей провайдеров.
  Например, OpenRouter использует `llm_api_key`, Cerebras - `cerebras_api_key`,
  «Свой» - `custom_llm_api_key`. Выбирай провайдера через настройки своей установки,
  не заменяй Workshop-загрузчик проектным и не копируй чужой конфиг/ключи.
* `keys.json` не публикуется в репозитории, но локальное хранение не означает
  отсутствие внешних запросов: ключ авторизует запрос к выбранному провайдеру.
  Диалоги, память, промпты и голосовой ввод могут содержать личные данные.
* Экспорт переносит настройки, персоны, историю и состояние событий в ZIP с JSON;
  API-ключи добавляются **только по явному выбору**. Архив **не зашифрован**, включая
  ключи, если они добавлены. Не публикуй его; импорт проверяет содержимое и делает
  резервную копию заменяемых файлов в `import_backups/` папки данных.
* Для публичного пакета оставляй канонического игрока **Семён** и стандартную
  персону (либо пустую), не личное имя/биографию. Свой профиль меняй в настройках
  установленного мода; персоны NPC перед публикацией требуют ручной проверки.

## Требования

* Windows, **Бесконечное лето** в Steam (Ren'Py 7.4.11 / Python 2.7 внутри игры).
* **Python 3.10+** на машине (сервер и окно настроек). Для edge-tts и микрофона —
  `edge-tts`, `sounddevice`, `numpy` (кнопка установки компонентов или
  `python -m pip install -r ES-AI-Mod/server/requirements.txt` из корня проекта).
* По желанию: `pyttsx3` для локального Windows SAPI, `faster-whisper` для локального
  STT, Pillow (`PIL`) для дополнительных графических возможностей окна настроек.
  Они не входят в базовую кнопку установки; локальным моделям нужны свои ресурсы.

## Разработка

* Правка файлов в `ES-AI-Mod/mod/` и `ES-AI-Mod/server/`, затем ручная установка
  через `installer.pyw`. Это проектный вариант, не развёртывание Workshop.
  Ren'Py пересобирает `.rpyc` при запуске игры.
* Проверка сервера без игры:

  ```powershell
  python ES-AI-Mod/server/main.py --check
  python ES-AI-Mod/server/main.py
  ```

* Логи: `log.txt` в корне игры (сторона Ren'Py) и консоль сервера (сторона Python).
* Игра внутри — **Python 2.7**: никаких `async`, `Thread(..., daemon=True)`,
  `requests`; сеть — `urllib2`, фоновые задачи — `threading.Thread` + `renpy.pause`.

### Офлайн-тесты

Из корня репозитория, независимо от имени папки проекта:

```powershell
python -m unittest discover -s ES-AI-Mod/server -p "test_*.py"
```

`test_paths.py` вычисляет корень проекта по своему расположению, не по CWD и не по
имени `Endless Summer`. Необязательные переменные окружения:

* `ESAI_WORKSHOP_ROOT` - путь к установленному Workshop-моду, где `.rpy` лежат
  непосредственно в корне, а Python-сервер - в `server/`.
* `ESAI_GAME_ROOT` - корень игры с `game/` и встроенным Python 2.
* `ESAI_TEST_TEMP` - существующая доступная папка для временных тестовых данных;
  по умолчанию используется системная временная папка.

Без переопределений используются известные локальные пути, только если они
существуют. Отсутствующие игра/Workshop приводят к пропуску соответствующих
необязательных проверок; пустое или несуществующее явное переопределение не
подменяется живой установкой. Для запуска только переносимых проверок в PowerShell:

```powershell
$env:ESAI_WORKSHOP_ROOT = Join-Path $env:TEMP "esai-absent-workshop"
$env:ESAI_GAME_ROOT = Join-Path $env:TEMP "esai-absent-game"
python -m unittest discover -s ES-AI-Mod/server -p "test_*.py"
```

Набор покрывает доставку, группы/nearby, занятия, память, спутников, события,
локации, часы, одежду, настройки, провайдеров и перенос/развёртывание данных.
Количество тестов меняется; офлайн-проверки с подменёнными LLM и Ren'Py не доказывают
качество реальных ответов, согласованность долгой игровой сцены или полный запуск
игры. Проверка синтаксиса Python 2 также не заменяет загрузку мода в Ren'Py.

### Развёртывание Workshop

`tools/deploy_workshop.py` - отдельный офлайн-инструмент для существующей установки,
не установщик Workshop из GitHub. Сейчас установленный Workshop служит каноническим
источником Workshop-варианта; если его нет, для исходников используй собственный
`installer.pyw`. Проектный загрузчик не превращается автоматически в Workshop-версию.

Все команды ниже запускаются из корня репозитория; пути примеров нужно заменить.
Без действия инструмент выполняет `--check`: сравнивает проект и установленный
runtime, показывает общие и расходящиеся файлы и проверяет зависимости.

```powershell
python ES-AI-Mod/tools/deploy_workshop.py --check --target "D:\SteamLibrary\steamapps\workshop\content\331470\3809240310"
python ES-AI-Mod/tools/deploy_workshop.py --build "C:\esai-release\bundle" --target "D:\SteamLibrary\steamapps\workshop\content\331470\3809240310"
python ES-AI-Mod/tools/deploy_workshop.py --verify "C:\esai-release\bundle" --target "D:\SteamLibrary\steamapps\workshop\content\331470\3809240310"
```

`--build` по умолчанию снимает разрешённые runtime-файлы **с указанного Workshop**,
а не слепо копирует проект. Для подготовленного отдельного Workshop-источника
нужны одновременно `--source "C:\esai-release\staged-workshop" --flavor workshop`
при `--build`. Загрузчик, launcher, ключи провайдеров и маршрутизация данных должны
сохранять Workshop-контракты; автоматического слияния вариантов нет.

Снимок содержит manifest и хеши, но не runtime `config.json`, `keys.json`, память,
кэш или тесты. Статические встроенные defaults проверяются отдельно.
`--verify` проверяет состав, хеши, зависимости и неизменность целевого runtime
с момента сборки; это не проверка реального LLM или полный тест Ren'Py.

Применение изменяет установку **только по явной команде**, после закрытия игры и
сервера, и требует внешнюю резервную папку:

```powershell
python ES-AI-Mod/tools/deploy_workshop.py --apply "C:\esai-release\bundle" --target "D:\SteamLibrary\steamapps\workshop\content\331470\3809240310" --backup "C:\esai-release\backup"
```

Папки bundle/backup должны ещё не существовать, их родитель должен существовать;
они должны быть вне проекта, установки и пользовательских данных. Инструмент
повторно проверяет цель и сохраняет заменяемые runtime-файлы. Пользовательские
данные и скомпилированные файлы не копируются; после применения перезапусти игру.
Пути игры/Workshop здесь задаются CLI, а не тестовыми переменными `ESAI_*`;
`--python2` позволяет явно указать встроенный интерпретатор для проверки init-блоков.

## Известные ограничения

* «Озвучка романа» включается флагом `persistent.es_ai_novel_voice` (по умолчанию
  выключена; отдельного тумблера в UI пока нет).
* STT требует, чтобы сервер был запущен на той же машине, где микрофон.
* Доступность облачных API, моделей и тарифов зависит от провайдера и региона;
  возможны HTTP 403, лимиты и смена моделей. Локальные Ollama / LM Studio требуют
  отдельно запущенного сервера с загруженной моделью.
* Ответ LLM приходит целиком (индикатор «думает»), без потокового вывода.
