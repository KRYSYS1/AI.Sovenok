КАЛИТКА AI В ГЛАВНОМ МЕНЮ
=========================

Положи сюда СВОИ две картинки (PNG с прозрачным фоном):

  gate_idle.png   — обычное состояние
  gate_hover.png  — состояние при наведении курсора (например, «калитка открылась»)

Требования:
  * одинаковый размер у обеих картинок (смена выглядит как открытие);
  * прозрачность PNG настоящая (альфа-канал) — наведение срабатывает только
    на непрозрачных пикселях, пустые места «прозрачны» для курсора.

Позиция и масштаб настраиваются в файле mod/es_ai_gate.rpy
(ES_GATE_XALIGN / ES_GATE_YALIGN / ES_GATE_ZOOM).

Клик по картинке открывает мод «AI Совёнок».

Без этих двух файлов фича полностью отключается и меню выглядит как обычно.
